Проєкт "Застосунок для спільного ведення нотаток"

Застосунок для створення, редагування та спільного використання документів у реальному часі. Він підходить як для індивідуального ведення нотаток, так і для командної роботи.

Основні функції: редагування у реальному часі групових документів, зберігання історії версій, базові можливості форматування, можливість організовувати свій робочий простір.

Склад команди:
1. Супроводжувач репозиторію (Repo Maintainer) - Карнаух Дарія
2. Супроводжувач CI (CI Maintainer) - Козинська Анастасія
3. Керівник документації (Documentation Lead) - Марущенко Ольга
4. Керівник трекера завдань (Issue Tracker Lead) - Бідочка Ольга

Розташування посилань на Loom будуть у папці Labs, у якій будуть папки Lab01/Lab02/Lab03/та наступні.
