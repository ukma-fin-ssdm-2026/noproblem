# Changelog

Усі значущі зміни в цьому проєкті задокументовані в цьому файлі.

## [0.1.0] - стан до 2026-10-28

Базовий стан репозиторію на кінець 28 жовтня 2026 року
([`a30792a`](https://github.com/ukma-fin-ssdm-2026/noproblem/commit/a30792ae87bdc8001730805494102afe96d6aa19)),
до рефакторингів Лабораторної 8.

### Added

- FastAPI REST API для реєстрації, входу, керування документами й абзацами,
  кошиком, доступом за ролями, пошуком і календарними подіями.
- Можливість використовувати сховища в пам'яті або PostgreSQL для IAM,
  документів, абзаців, пошуку й календаря; SQL-міграції для схеми бази даних.
- Генерацію OpenAPI-специфікації та Swagger UI для API.

## [0.1.1] - 2026-11-04

  іменовані константи.
- **Анастасія Козинська — Replace Conditional with Map** ([#241](https://github.com/ukma-fin-ssdm-2026/noproblem/pull/241)):
  відповідність винятків і HTTP-відповідей перенесено в таблицю.
