# Матриця простежуваності (RTM)

Статус зазначено для кожної вимоги окремо: **Реалізовано** — вимога підтримується поточним API/серверною логікою; **Заплановано** — вимога ще потребує реалізації або перевірки в повному клієнт-серверному сценарії.
